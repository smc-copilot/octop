# Reply Polish

Improve the provided draft without changing its factual claims. Do not send.

## Guidelines

- Preserve the user's intent and key commitments.
- Fix grammar, tighten wording, and keep a professional tone.
- Keep plain text; do not invent new promises.
- Return the polished draft only, still editable by the user.
